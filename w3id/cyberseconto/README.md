# w3id.org/cyberseconto

Permanent identifiers for CyberSecOnto, the cybersecurity competencies ontology.

- Namespace: `https://w3id.org/cyberseconto/` (terms are `https://w3id.org/cyberseconto/<ID>`, ontology IRI `https://w3id.org/cyberseconto/cyberseconto`)
- RDF requests are redirected to the ontology file in the repository; browsers go to the repository page.
- Source and maintainer: https://github.com/ITriskMgr/CyberSecOnto, Marc-André Léger (marcandre@leger.ca)
